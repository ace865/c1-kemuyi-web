# C1 科目一通关助手全视觉重构设计规格

## 1. 目标

在保留现有题库、档案、刷题、错题本和模拟考试功能的前提下，完全替换当前黑白圆角卡片、漂浮光斑、胶片颗粒和普遍回弹的视觉语言。

新设计采用双场景体系：

- 日常学习使用明亮的“道路图鉴”视觉，强调长时间阅读、知识组织和学习进度。
- 模拟考试使用深色的“驾驶舱”视觉，强调专注、计时和任务感。
- 两个场景共享同一套字体、图标、状态色、间距和“通关路线”视觉语法，避免成为两套割裂皮肤。

目标用户是准备中国 C1 科目一考试的学习者；桌面端为主要场景，同时保持 320px 起的移动适配。

## 2. 品牌与视觉系统

### 2.1 核心概念

整套产品以“通关路线”为唯一签名元素：

- 首页显示全局路线和当前学习位置。
- 刷题每完成一道就推进一个路线节点。
- 错题显示为需要返程复习的路段。
- 模考将路线转化为 100 个连续考试节点。
- 通过考试时路线抵达终点并生成成绩报告。

路线必须承担进度、导航或状态含义，不作为无意义装饰。

### 2.2 日常学习配色

- `atlas-paper: #F4F1E8`：应用背景，暖矿物纸张感。
- `atlas-surface: #FFFDF7`：主要阅读区域。
- `atlas-ink: #13263A`：标题和正文主色。
- `atlas-muted: #66717D`：次级说明。
- `route-blue: #1F5E8C`：导航与中性进度。
- `route-green: #277A5A`：正确、完成和通过。
- `route-red: #B5473C`：错误、危险和删除。
- `route-amber: #D79A2B`：提醒和考试倒计时。

禁止使用紫蓝 AI 渐变、纯黑大面积背景、彩色状态以外的多重强调色。

### 2.3 模考配色

- `cockpit-bg: #101B24`：考试环境背景。
- `cockpit-panel: #182732`：仪表与答题卡表面。
- `cockpit-reading: #F7F3E8`：题目阅读区域，保持浅底深字。
- 复用 `route-amber`、`route-green`、`route-red` 表达计时与正误。

模考不是赛博朋克或游戏 HUD；不使用霓虹描边、扫描线和密集装饰。

### 2.4 排版与形状

- 中文正文使用系统可用的现代黑体栈，确保离线和 Windows 稳定渲染。
- 标题通过更紧字距、更大字号和较高字重建立编辑式层级，不依赖网络字体。
- 数据和倒计时启用等宽数字特性。
- 外层容器半径 16px，交互控件 10px，标签和路线节点 4–8px；禁止所有元素使用相同大圆角。
- 主要内容最大宽度约 1240px，并使用非对称 12 列网格。

## 3. 页面设计

### 3.1 启动与档案

- 删除强制 1.5–3 秒等待和华丽开屏。
- 启动页只显示路线从起点延伸的 400–700ms 品牌动画；数据完成后立即进入档案页。
- 档案以驾驶证资料页的编辑式排版呈现，但不仿造真实证件。

### 3.2 首页

- 左侧为“继续学习”主任务和通关路线，右侧呈现今日进度、正确率、错题等关键数据。
- 刷题、模考、错题不再是三个同尺寸卡片；用一主两辅的非对称布局表达优先级。
- 数据直接显示最终值，不重复播放长数字滚动。

### 3.3 刷题

- 大题号与题型成为页面入口点，题干行宽限制在舒适阅读范围。
- A–D 选项采用路线分叉式结构，点击区域完整、键盘焦点明确。
- 作答后立即显示正误；练习模式显示正确答案和解析。
- 正确时点亮下一段路线，错误时显示返程标记；不叠加粒子、抖动和 CSS 回弹三套反馈。

### 3.4 错题本

- 使用“待返程路段”列表，支持全部、刷题、模考来源筛选。
- 每条内容显示来源、题干摘要和移除操作，删除使用轻量收拢动画。
- 空状态给出返回刷题的明确入口。

### 3.5 模拟考试

- 进入考试后切换深色驾驶舱环境，但题干和选项仍位于浅色阅读面板。
- 顶部展示题号、进度、剩余时间和交卷动作；100 题答题卡使用路线节点组织。
- 用户作答后立即看到正确或错误状态，但考试过程中不显示答案解析。
- 用户可返回已答题并修改选择；修改后同步更新状态和持久化答案。
- 退出考试、切换档案、交卷时必须取消倒计时和自动跳题任务。

### 3.6 成绩与复盘

- 成绩页表现为路线行程报告，先呈现是否通过、分数、用时和未答数量。
- 交卷后复盘允许查看正确答案和解析。
- 通过时仅执行一次终点展开动画，不使用满屏彩纸。

## 4. 动效系统

- 微反馈 120–180ms，组件状态 180–260ms，页面切换 280–360ms，启动和结果仪式最多 700ms。
- 页面移动使用平滑减速，不使用明显过冲；回弹只保留给按压和局部确认。
- 动画统一由明确的一套机制负责，避免 CSS keyframes、Web Animations 和自定义弹簧同时修改同一元素的 `transform`。
- 只动画 `transform` 和 `opacity`；删除页面转场中的大面积 `filter: blur`、常驻颗粒和巨大混合模式图层。
- 自定义弹簧若保留，必须使用真实帧间隔；否则改为统一的 CSS/WAAPI 缓动令牌。
- 完整支持 `prefers-reduced-motion`，减少动效时直接显示最终状态。

## 5. 工程结构

- 保留原生 HTML、CSS、JavaScript 和 Electron，不引入前端框架或在线资源。
- 将现有单体样式整理为设计令牌、基础布局、组件、页面和动效几个明确分区；可拆分 CSS 文件，但必须保持离线加载。
- 将 `app.js` 中视觉渲染与动效协调逻辑按首页、练习、错题、考试拆分为可理解模块；考试和存储领域逻辑继续复用现有模块。
- 不改变已有本地存储 key 和版本，保证现有档案可继续读取。

## 6. 同轮缺陷修复

- `loadProfileData()` 必须读取、校验并返回 `wrongSources`；清洗时只保留有效题目 ID 和 `practice | exam` 值，保存—重启—读取后来源筛选保持一致。
- 建立统一的考试定时任务清理函数，同时清除每秒倒计时和 800ms 自动跳题；在离开考试、切换档案、开始新考试、交卷和重新初始化时调用。
- 模考即时正误反馈保留；确认考试作答阶段不存在解析内容，解析只在交卷复盘出现。

## 7. 验收标准

- 所有现有自动检查继续通过，并补充错题来源持久化、自动跳题清理和模考解析可见性测试。
- 桌面宽屏、1024px、767px 和 390px 布局无横向溢出，主要操作保持可见。
- 键盘可完成档案选择、导航、答题、交卷和复盘；焦点样式清晰。
- 正常与减少动效模式都能完成所有流程。
- 本地题库和图片保持完全离线，Electron 的 CSP、沙箱和网络阻断不削弱。
- 视觉上不再出现当前黑白卡片墙、常驻漂浮装饰、胶片颗粒、全局回弹和满屏彩纸。
