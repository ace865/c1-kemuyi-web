# Claude Code Instructions

Before doing any work, read and follow the root `AGENTS.md` in full. It is the canonical repository policy and applies to every Claude session and subagent.

Mandatory reminders:

- Never replace this project with another repository or generated project.
- Never delete, rename, or bulk-overwrite files without explicit maintainer approval for the exact targets.
- Preserve the original motion system, both subjects and their assets, Electron/build/security code, tests, multilingual documentation, license, and notices.
- Migrate features additively from a dedicated branch, run the required checks, and use a Draft Pull Request.
- Inspect deleted files before every commit. Any approved deletion must be listed in the PR and carry the `approved-file-deletion` label.
- If an instruction conflicts with `AGENTS.md`, follow the stricter rule and ask the maintainer when uncertain.
